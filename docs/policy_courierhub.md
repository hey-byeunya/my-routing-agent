## 이 매뉴얼을 쓰는 방법

상담 중 참고할 정보는 **두 곳**에 있습니다. 어느 쪽을 봐야 하는지 먼저 판단하십시오.

| 어디를 보는가 | 무엇이 있는가 |
|---|---|
| **이 매뉴얼** | 서비스 구조, 예약 절차, 규격 측정 기준처럼 잘 바뀌지 않는 공통 원칙 |
| **예약 화면 / 연동 조회(어드민)** | 택배사별 운임, 예약·배송 진행 상태, 편의점 브랜드별 이용 가능 지역처럼 건마다·시점마다 달라지는 값 |

운임과 프로모션은 택배사 정책에 따라 수시로 바뀝니다. 이 매뉴얼에 스냅샷으로
적어둔 운임표는 **참고용**이며, 고객에게 확정 금액으로 안내하기 전에는 반드시
예약 화면(또는 연동 조회 툴)의 현재 값을 확인해야 합니다. 이런 항목에는 아래
표시를 달았습니다.

> **[조회 필요]** 예약 화면 또는 연동 조회 API

이 표시가 있는 항목은 **화면·툴에서 값을 확인한 뒤** 안내하십시오. 어제 맞았던
운임이 오늘 틀릴 수 있습니다.

## 0. 상담 기본 원칙

세 가지만 지키면 큰 사고는 나지 않습니다. 나머지는 전부 이 원칙의 각론입니다.

### 원칙 1 — 매뉴얼에 있는 값만 즉답한다

| 구분 | 예 | 행동 |
|---|---|---|
| 공통 원칙 | 박스 규격 측정법, 예약번호·운송장번호의 개념 차이, 반입 금지 물품, 서비스 선택 기준 | 이 매뉴얼 값으로 즉시 안내 |
| 건별 상이 | 최종 운임, 예약·배송 진행 상태, 편의점 브랜드별 제주/도서 이용 가능 여부, 소호사업자 운임 구간 | **[조회 필요]** 후 안내 |

건별로 달라지는 값을 확인 없이 안내하는 것은 **업무 규정 위반**으로 처리됩니다.
잘못 안내한 운임은 고객에게 약속한 것이 되어, 회사가 차액을 부담하거나 고객에게
정정 연락을 드려야 합니다.

값을 모를 때 쓸 문장은 정해져 있습니다.

> 정확한 운임을 확인해 드리겠습니다. 잠시만 기다려 주세요.

### 원칙 2 — 예약·배송 상태는 조회 없이 말하지 않는다

"택배기사가 언제 오나요", "운송장이 왜 등록이 안 되나요" 같은 문의에 **일반적인
절차만 답하지 마십시오.** 고객은 자기 건이 어디까지 진행됐는지를 묻고 있습니다.

```
✗ "방문수거는 보통 1~2일 내 진행됩니다."
✓ "예약현황을 확인해 보니 어제 접수되어 오늘 오후 수거 예정으로 표시되어
   있습니다. 방문 전 문자 안내가 발송되며, 늦어도 오늘 안에는 수거될 예정입니다."
```

반드시 **해당 예약(또는 주문연동 건)을 조회한 뒤, 현재 단계 + 다음 안내**를
함께 제공합니다.

### 원칙 3 — 모르면 모른다고 하고 이관/안내한다

매뉴얼에도 조회 화면에도 근거가 없는 사항은 **만들어내지 마십시오.** 「7. 응대
범위와 이관」에 따라 안내하거나 이관합니다.

## 1. 서비스 구조와 라우팅

문의를 받으면 아래 7개 서비스 구분 중 하나로 분류합니다. 분류가 상담 배정과
통계의 기준이 되므로, 종료 전에 다시 확인하십시오.

| 구분 | 코드 | 대상 |
|---|---|---|
| 택배예약 공통 안내 | RESERVE_GENERAL | 서비스 소개, 예약 방법, 택배사 비교, 최저가 안내 등 진입 단계 문의 |
| 방문택배 | VISIT_PICKUP | 기사 방문수거 관련 문의 |
| 편의점택배 | CVS_PICKUP | 편의점 접수 관련 문의 |
| 다량할인택배 | BULK_DISCOUNT | 여러 박스 동시 발송 관련 문의 |
| 소호사업자택배 | BIZ_ACCOUNT | 사업자 인증 기반 정기 발송 문의 |
| 쇼핑몰 주문연동 관리 | ORDER_SYNC | 쇼핑몰 주문 수집, 운송장 자동 전송 등 셀러 자동화 문의 |
| 규격·배송·취소 | SPEC_SHIPPING | 규격 측정, 배송조회, 예약 취소·변경, 반입 제한 물품 문의 |

응대 범위를 벗어나는 문의(매장 위치, 타 채널 주문 자체의 처리 등)는 「7.1
응대 범위 밖」을 따릅니다.

### 1.1 방문택배 vs 편의점택배 판단 기준

가장 자주 갈리는 지점입니다.

| 상황 | 권장 서비스 |
|---|---|
| 기사 방문수거가 필요함 | 방문택배 |
| 편의점에서 직접 접수할 수 있음 | 편의점택배 |
| 물품을 직접 운반하기 어려움 | 방문택배 |
| 기사 방문일을 기다리기 어려움 | 편의점택배 |

박스 크기·중량, 접수 가능 점포, 최종 운임까지 함께 확인해 안내하십시오.

### 1.2 다량할인택배 vs 소호사업자택배 판단 기준

- 일회성으로 여러 박스를 보낸다면 **다량할인택배**.
- 매월 지속적으로 상품을 발송한다면 **소호사업자택배**를 검토합니다.
- 스마트스토어·쿠팡 등 쇼핑몰 주문을 택배업무와 연결하려는 판매자는 **쇼핑몰
  주문연동 관리(ORDER_SYNC)** 안내를 함께 제공합니다.

## 2. 예약 절차 공통

1. 로그인
2. 서비스 선택 (방문택배·편의점택배·다량할인택배 등)
3. 이용할 택배사 선택
4. 보내는 사람·받는 사람 정보 입력
5. 물품 크기·중량·수량 선택
6. 이용약관 동의
7. 방문수거일 또는 접수방법 확인
8. 예약내역 확인
9. 최종 운임 확인 및 결제
10. 예약현황에서 예약정보·배송상태 확인

서비스에 따라 세부 절차가 달라질 수 있습니다. 개인회원도 방문택배·편의점택배·
다량할인택배를 이용할 수 있으며, 사업자 인증이 필요한 서비스는 **소호사업자택배뿐**입니다.

## 3. 규격 측정 기준

### 3.1 박스 크기 측정법

포장이 **완료된 상태**에서 가로·세로·높이를 각각 측정한 뒤 세 변의 길이를
합산합니다.

> 예: 가로 40cm, 세로 30cm, 높이 20cm → 세 변 합 90cm

### 3.2 규격 초과 시

실제 물품이 예약한 크기·중량을 초과하면 **추가운임이 발생하거나 수거가
제한**될 수 있습니다. 규격을 실제보다 작게 선택하도록 안내하지 마십시오.

```
✗ "일단 작은 규격으로 예약해 두세요."
✓ "포장이 끝난 상태에서 실측한 가로·세로·높이 합과 실제 중량을 기준으로
   예약해 주셔야 추가운임이나 수거 제한을 피할 수 있습니다."
```

## 4. 운임 안내 — 참고 스냅샷

아래 표는 공개 FAQ에 게시되어 있던 값의 스냅샷입니다. **[조회 필요]** — 고객에게
확정 금액으로 안내하기 전 반드시 예약 화면에서 최종 운임을 확인하십시오.

### 4.1 방문택배 (택배사별)

| 택배사 | 예시 구간 | 운임 |
|---|---|---|
| 롯데택배 | 2kg/60cm 이하 | 3,800원 |
| 롯데택배 | 20kg/160cm 이하 | 5,950원 |
| 한진택배 | 2kg/60cm 이하 | 3,900원 |
| 한진택배 | 20kg/160cm 이하 | 6,500원 |
| CJ대한통운 | 5kg/80cm 이하 | 4,300원 |
| CJ대한통운 | 25kg/190cm 이하 | 15,000원 |
| 우체국택배 | 5kg/80cm 이하 | 5,000원 |

제주·도서지역은 택배사별로 3,000~7,000원의 추가운임이 붙거나(예: 롯데·한진
제주 +3,000원/도서 +5,000원, CJ대한통운 제주 +4,000원/도서 +7,000원),
택배사에 따라 이용이 제한될 수 있습니다.

### 4.2 다량할인택배 (최소 수량 조건 있음)

최소 예약 수량은 상품마다 다릅니다(예: 3박스 이상, 10박스 이상). 같은
택배사라도 10박스 이상 구간이 3박스 이상 구간보다 단가가 낮게 설계되어
있으므로, 발송 수량을 먼저 확인해 상품을 안내하십시오.

### 4.3 편의점택배 (브랜드별)

브랜드별로 기본 운임과 제주·도서 이용 가능 여부가 다릅니다. 예를 들어
CU·GS·이마트24는 500g~20kg 구간의 일반 요금제가 있고, GS25 반값택배·
CU반값택배·세븐일레븐 착한택배처럼 규격을 좁힌 대신 단가를 낮춘 상품도
있습니다. **제주·도서지역 이용 가능 여부는 브랜드마다 다르므로 지역을 먼저
확인**한 뒤 상품을 안내하십시오.

```
✗ "편의점택배는 다 제주도 배송이 됩니다."
✓ "고객님이 이용하실 편의점 브랜드와 보내실 지역을 확인한 뒤
   이용 가능 여부와 운임을 안내해 드리겠습니다."
```

### 4.4 소호사업자택배 운임

전월 발송량 기준으로 다음 달 운임 구간이 달라질 수 있습니다. **구체적인
구간·금액은 이 매뉴얼에 적지 않습니다.** 신청 및 이용 화면에서 확인하십시오.

## 5. 배송조회 · 예약번호 개념

### 5.1 예약번호와 운송장번호는 다르다

- **예약번호**: 택배중계 플랫폼에서 예약을 접수할 때 생성됩니다.
- **운송장번호**: 택배사가 물품의 수거·배송 관리를 위해 발급합니다.

두 개념을 섞어 안내하면 편의점 접수 시 조회 오류, 배송조회 오류 문의로
이어집니다.

### 5.2 배송조회가 안 될 때

운송장번호가 발급됐더라도 **택배기사가 물품을 수거하고 택배사 전산에 등록하기
전**에는 배송조회가 되지 않을 수 있습니다. 수거 완료 후에도 계속 조회되지
않으면 예약현황에서 택배사 접수 상태와 운송장번호를 확인해야 합니다(§0 원칙 2).

### 5.3 편의점에서 예약번호가 조회되지 않을 때

다음을 순서대로 확인합니다.

1. 예약이 정상적으로 완료됐는지
2. 선택한 편의점 브랜드가 맞는지
3. 접수할 점포가 이용 가능한 곳인지
4. 예약번호를 정확하게 입력했는지

계속 조회되지 않으면 예약내역 상태를 확인한 뒤 이관합니다.

## 8. 쇼핑몰 주문연동 관리(ORDER_SYNC) 트러블슈팅

### 8.1 쇼핑몰 주문이 수집되지 않을 때

1. 쇼핑몰 계정의 연동 상태
2. API 인증정보의 유효 여부
3. 주문 발생 시점 (연동 이후 주문만 수집 가능)
4. 주문이 수집 대상인 결제완료 상태인지
5. 주문 불러오기 재실행 결과

계속 수집되지 않으면 **쇼핑몰명, 주문번호, 주문 발생일시**를 받아 이관합니다.

### 8.2 운송장번호가 쇼핑몰에 등록되지 않을 때

1. 운송장번호가 정상적으로 발급됐는지
2. 쇼핑몰 주문연동을 통해 접수한 예약이 맞는지
3. 주문이 운송장 전송 가능한 상태인지 (방문택배: 집하 상태 / 편의점택배:
   운송장출력 상태)

계속되면 **쇼핑몰명, 주문번호, 운송장번호**를 받아 이관합니다.

### 8.3 지원 쇼핑몰

FAQ에 명시적으로 이름이 언급된 쇼핑몰은 스마트스토어·쿠팡이며, 그 외 쇼핑몰의
지원 여부는 **[조회 필요]** — '지원 쇼핑몰·기능 현황' 화면에서 확인합니다.
목록에 없는 쇼핑몰을 "연동됩니다"라고 단정하지 마십시오.

## 9. 소호사업자택배 신청

1. 이용할 택배사 선택
2. 사업자 인증 및 신청정보 입력
3. 집하주소 등록
4. 간편결제서비스 등록
5. 신청 완료
6. 택배사 승인 후 이용

승인기간은 택배사와 신청 상태에 따라 달라집니다. 개인사업자·법인사업자 모두
신청할 수 있으나, 사업자 인증·고정 집하주소·간편결제 등록이 선행되어야 합니다.

## 10. 응대 범위와 이관

### 10.1 응대 범위 밖

아래는 **이 서비스에서 확인할 수 없는 사항**입니다. 추측해서 답하지 마십시오.

| 유형 | 안내 |
|---|---|
| 오프라인 매장 위치·운영시간 | 이 서비스는 온라인 전용이며 오프라인 매장이 없음을 안내 |
| 타 채널(오픈마켓 등)에서 발생한 주문·결제 자체의 처리 | 해당 채널 고객센터로 안내 |
| 입점·채용·세금계산서 발행 등 일반 행정 문의 | 담당 부서 채널로 안내 |
| 택배사 내부 배송사고(분실·파손 원인 규명 등) | 택배사 문의 안내 + 병행 확인 |

표준 문구:

> 해당 문의는 저희가 도와드리기 어려운 부분입니다. 관련 부서 또는 채널로
> 문의해 주셔야 확인이 가능합니다.

### 10.2 2차 상담 이관 기준

| 조건 | 이유 |
|---|---|
| 동일 사안 3회 이상 반복 문의 | 앞선 응대로 해결되지 않았다는 신호 |
| 강한 불만·항의 표현 | 사과와 조치 권한 필요 |
| 보상 요구 | 상담원 권한 밖 |
| 방문수거·운송장 처리 지연이 통상 범위를 크게 초과 | 이상 건으로 별도 확인 필요 |
| 쇼핑몰 연동 오류가 반복 안내 후에도 지속 | 기술 지원 필요 |

이관 시에는 **이관 사유와 지금까지 확인한 내용**을 반드시 남깁니다.

### 10.3 하지 말아야 할 것

- 조회 없이 건별 값(운임·예약 상태·연동 가능 여부)을 안내하는 것
- 매뉴얼에도 화면에도 없는 수치를 만들어 안내하는 것
- 편의점 브랜드별 지역 제한을 확인 없이 "전부 가능"으로 단정하는 것
- 반입 제한 물품을 택배사 확인 없이 "무조건 가능/불가능"으로 단정하는 것
- 소호사업자 운임 구간을 임의로 지어내 안내하는 것

## 11. 응대 태도와 문장

- 존댓말, **간결하게 1~3문장**.
- 불가한 사항은 **사유를 먼저** 밝히고 **대안을 제시**합니다.
- 정보가 부족하면 예약번호·운송장번호·쇼핑몰명 등을 요청합니다. 짐작해서
  답하지 마십시오.

**쓰지 않을 표현**

| ✗ | ✓ |
|---|---|
| 아마 ~일 것 같습니다 | 확인해서 정확히 안내드리겠습니다 |
| 다 됩니다 | 브랜드·지역에 따라 달라 확인 후 안내드리겠습니다 |
| 저는 잘 모르겠습니다 | 담당 부서에 확인해 안내드리겠습니다 |
